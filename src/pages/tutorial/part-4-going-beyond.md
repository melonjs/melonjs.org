# Part 4: Going beyond

You built a platformer. Here is where to go next.

## Add to your game

Enemies to jump on, coins to collect, a second level. The
[platformer example](https://melonjs.github.io/melonJS/examples/#/platformer)
has all three. Its
[source](https://github.com/melonjs/melonJS/tree/master/packages/examples/src/examples/platformer)
is built the same way as your project, so you can read it and borrow from it.

## See what else melonJS does

- [All the examples](https://melonjs.github.io/melonJS/examples/), from an
  isometric RPG to 3D scenes
- [The API reference](https://melonjs.github.io/melonJS/), for every class and
  method

## Let an AI assistant help

melonJS ships 23 skills that teach a coding agent how the engine works. They
also cover the quiet mistakes from the end of Part 3-3. One command installs
them:

```bash
npx skills add https://github.com/melonjs/melonJS/tree/master/packages/melonjs/skills
```

More about this on the [homepage](/#ai-skills).

## Think about design

Code is half of a game. For the other half:

- [Game design as a creative process](/game-design-creative-resources)
- [The basics of art](/learn-about-art)

## When you get stuck

Ask on [Discord](https://discord.gg/aur7JMk). The maintainers are there, and so
are other people building games. The
[wiki](https://github.com/melonjs/melonJS/wiki) covers guides the reference does
not.
