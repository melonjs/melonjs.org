# Part 4: Going beyond this tutorial

Congratulations! If you have made it this far you have a platformer you built
yourself, and everything below is about making it into a game you would want to
play.

## Keep building this one

- Enemies to jump on, coins to collect, and a second level: the
  [platformer example](https://melonjs.github.io/melonJS/examples/#/platformer)
  has all three, and its
  [source](https://github.com/melonjs/melonJS/tree/master/packages/examples/src/examples/platformer)
  is the same shape as the project you just made.
- [Every other example](https://melonjs.github.io/melonJS/examples/), from an
  isometric RPG to 3D scenes, with source for each.
- The [API reference](https://melonjs.github.io/melonJS/) for everything the
  engine can do.

## Get an AI assistant to help

melonJS ships 23 skills that teach a coding agent the engine's conventions, and
the mistakes that fail silently rather than erroring, including the three at the
end of Part 3-3. One command installs them into whichever agent you use:

```
npx skills add https://github.com/melonjs/melonJS/tree/master/packages/melonjs/skills
```

There is more on the [homepage](/#ai-skills).
