# melonJS: Build a Platformer Game

<Icon icon="melon-hack" class="small" alt="Melon hacked clip art" />

This tutorial walks you through building a side-scrolling platformer, the kind
of game where you run and jump across a level. You will scaffold a real melonJS
project, draw a level in a map editor, and write the code that makes a character
move. By the end you will have a game running in your browser that you can keep
building on.

Making a videogame can include a lot of skills, including but not limited to
art, coding, writing, and more. This course will talk about the skills that you
need and provide some resources, but it will not hold your hand or go in depth.
You will find a lot more success when developing games by being very proactive
in your learning and asking a lot of questions. This tutorial is a technical
explanation of how to make games, but it does not explain the creative process
of game design.

If you would like to learn more about the creative processes behind game design,
please [see here.](/game-design-creative-resources)
