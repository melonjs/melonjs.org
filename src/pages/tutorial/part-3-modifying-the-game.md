# Part 3: Building the game

Your project shows `Hello World!`. Three steps turn it into a platformer, and
each one uses a different tool.

- [Part 3-1: The art](/tutorial/part-3-1-modifying-the-art) explains the images
  a game uses. **Optional**, the art is already in your project.
- [Part 3-2: The level](/tutorial/part-3-2-modifying-the-level) loads a map and
  lets you edit it in Tiled. **Start here.**
- [Part 3-3: The code](/tutorial/part-3-3-modifying-the-code) makes your
  character run and jump.

Do 3-2 first if you want to see something on screen quickly. It is the step that
makes your game look like a game.
