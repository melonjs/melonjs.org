A modern & fully featured HTML5 game engine

melonJS is an open-source 2D & 3D game engine made for indie developers, and one of the very first HTML5 game engines: first released in 2011, it has grown with the web ever since. Perspective and orthogonal cameras, GPU-accelerated tilemaps, 3D meshes & glTF scenes, post-processing and custom shaders, polygon-accurate physics. Runs on WebGPU, WebGL 2 or Canvas2D with automatic fallback, in ~250 KB minzipped of vanilla JS/TS, with no dependencies and no toolchain lock-in.

Why melonJS?

melonJS is designed so you can focus on making games, not on graphics plumbing.

Canvas2D-Inspired API

If you've used the HTML5 Canvas, you already know melonJS. The rendering API (save, restore, translate, rotate, setColor, fillRect, ...) follows the same familiar patterns. No render graphs, no shader pipelines, no instruction sets to learn.

WebGPU, WebGL 2 or Canvas2D

Write your game once, run it on any backend with zero code changes. The default AUTO mode tries WebGPU first, falls back to WebGL 2, and ultimately to Canvas, and the entire feature set renders identically on both GPU backends.

Complete Engine, Minimal Footprint

Physics, tilemaps, audio, input, cameras, tweens, particles, UI: a full game stack in a single ES module. No dependency sprawl, no library stitching.

Scenes, Loaded in One Call

level.load(name) brings an authored scene straight into your world. Tiled is a first-class citizen for 2D, and glTF / GLB is its equivalent for 3D: author in Blender, export a .glb, and the whole scene (meshes, materials, cameras, lights and node animation) loads under a Camera3d.

Batteries Included

Get started in minutes with minimal setup. Sprites, animations, 3D meshes with dynamic lighting and ground shadows, built-in & custom shaders, spatial audio and particle effects, ready to use out of the box.

Hackable by Design

ES6 classes throughout, a plugin system for engine extensions, and a clean architecture that's easy to extend without fighting the framework. Go as deep as you need.

Features

Rendering

  • WebGPU & WebGL 2 renderers across desktop and mobile, with automatic fallback to Canvas
  • GPU-accelerated tile rendering for orthogonal Tiled maps: one quad per layer, no per-tile loop
  • Shader effects on sprites, cameras and meshes: Flash, Outline, Glow, Bloom, Dissolve, CRT, Hologram, Shine, Vignette, Squish, Sway and more, chained with addPostEffect()
  • Your own ShaderEffect in GLSL and/or WGSL, and optional HDR rendering
  • Particles, trails, tweens and video sprites

3D

  • Optional perspective camera (Camera3d) with frustum culling and distance fog
  • Sprite3d billboards for 2.5D characters and props
  • 3D meshes from OBJ/MTL or glTF, with normal maps, transparency, depth testing and GPU instancing (InstancedMesh)
  • glTF / GLB scenes, authored in Blender or any glTF tool, loaded with a single level.load(): meshes, materials, cameras, lights and node animation

Lighting & Cameras

  • Light2d with normal-map sprite shading
  • Light3d directional, point, spot & ambient lights (up to 32), with ground shadows on by default
  • Multiple cameras (split-screen, minimaps), camera follow, shake and fade, and screen transitions

Physics

  • Polygon SAT collision, QuadTree/Octree broad-phase, 2D & 3D raycasts
  • Sensors, and bodies with several shapes
  • Three official adapters, Matter, Planck and Rapier, switched while the game runs, with hinge, rope, weld and slider joints

Audio, Input & UI

  • Web Audio with 3D spatial sound, stereo panning, audio sprites and procedural SFX
  • Mouse, touch, keyboard, gamepad & accelerometer, and on-screen touch controls that play as a gamepad (gamepad plugin)
  • UI toolkit: buttons, scrolling panels, checkboxes, sliders, progress bars and drag-and-drop, all navigable with the keyboard or a gamepad
  • System & bitmap text with typewriter and per-glyph effects

Workflow

  • Full Tiled integration, up to Tiled 1.12: any map format and orientation, animated tilesets, custom properties, parallax layers, native .aseprite tilesets
  • Spine 4.3 runtime integration via the official plugin
  • Saved progress in localStorage, or in a platform's cloud save
  • State manager, asset loader & plugin system
  • ~250 KB minzipped, zero dependencies

Get Started in Seconds

Scaffold a new project with a single command:

~ 
$ npm create melonjs@latest my-game
Done! Created my-game.
$ cd my-game
$ npm install
$ npm run dev

Or use the API directly for a quick Hello World:

import { Application, Text } from "melonjs";

// create a new melonJS application
const app = new Application(1218, 562, {
    parent: "screen",
    scale: "auto",
});

// initialize it (builds the renderer and appends the canvas)
await app.init();

// add a text display object
app.world.addChild(new Text(609, 281, {
    font: "Arial",
    size: 160,
    fillStyle: "#FFFFFF",
    textBaseline: "middle",
    textAlign: "center",
    text: "Hello World !",
}));

Publish Anywhere

A melonJS game runs anywhere a browser does, and further: in game portals, in native apps, and in runtimes with no web page at all. The wiki has a guide for each, and melonJS hands pausing, saving and sound over to the platform the same way on every one of them.

The Web

Your own site, itch.io, or any host that serves a web page: a melonJS game is a web page.

YouTube Playables

Games in the YouTube app and on youtube.com, with cloud saves.

Poki

Hand-picked browser games on poki.com, on desktop and mobile.

CrazyGames

Browser games on crazygames.com and in the CrazyGames app.

Facebook Instant Games

Games in the Facebook app, on facebook.com/gaming and in Messenger.

WeChat Mini Games

Mini games inside the WeChat app.

iOS & Android

Native apps for the App Store and Google Play through Capacitor, with the official plugin.

Nintendo Switch Homebrew

Through nx.js, a runtime with no web page at all (experimental).

See Platforms in the wiki to get started.

AI Skills

melonJS ships 25 skills that teach a coding agent the engine's conventions, and the mistakes that fail silently rather than erroring: a custom draw() that ignores this.pos, isKinematic blocking pointer events, draw order set after addChild.

Install them into whichever agent you use:

~/my-game 
$ npx skills add https://github.com/melonjs/melonJS/tree/master/packages/melonjs/skills
•  Found 25 skills
•  Installing all 25 skills
•  77 agents
•  Installing to: Claude Code

$ claude
> Add a bouncing crate with SAT collision to my Tiled level.

One command, no config. The skills land in .agents/skills/, the shared location 77 agents read from, and the installer symlinks them into whatever else your editor expects, so nothing is placed by hand.

Claude Code

Takes them as a plugin instead, registering the same guidance as 25 routed skills. 

/plugin marketplace add melonjs/melonJS

Codex, Cursor, Gemini CLI

Anything following the AGENTS.md convention reads it from your project root. Copy the one that ships with the package, or paste its sections into yours. 

cp node_modules/melonjs/skills/AGENTS.md .

Pinned to Your Release

The command above installs from master. The copy matching the version you depend on ships in the npm package, one directory per subsystem. 

node_modules/melonjs/skills/

Then just describe what you want, as above. The melonjs skill routes to the guide that fits, out of physics, tilemaps, sprites, 3D scenes, lighting, shaders, audio, input, UI, performance and the rest, so your agent reads the one or two that matter rather than everything.

Compatibility

Compatible with all major browsers and mobile devices.

The published bundle targets ES2022. A browser that does not support it cannot parse the file at all: loading fails with a syntax error and a blank screen, rather than breaking later when some feature runs.

To support older browsers, transpile melonJS together with your own code. See Supporting older browsers in the README.
